## 功能验收

- [ ] **AC1 默认查询**：打开订单列表页 → Network 首条请求为 `/api/v1/orders?page=1&page_size=10&sort_by=created_at&sort_order=desc`；表格 10 行、下单时间倒序、状态列为中文 Tag；分页器 total 与响应 `total` 一致。
- [ ] **AC2 草稿零请求**：在表单输入订单号 `EF2026-`、多选状态、修改时间区间 → Network 面板**无任何新的 `/api/v1/orders` 请求**；列表数据不变；此时打开「导出筛选结果」弹窗，范围行数仍为上一次提交查询的 total。
- [ ] **AC3 点查询**：填 状态=PAID+SHIPPED、金额 100~5000、时间区间 → 点查询 → 请求含 `order_status=PAID,SHIPPED`、`total_amount_min=100`、`total_amount_max=5000`、`created_at_begin/end` 为本地格式（**无 `Z` 后缀与时区偏移**）；此前停在第 2 页的页码回到 1；列表与 total 刷新。
- [ ] **AC4 点重置**：先设筛选条件、勾选 2 条、页码到第 3 页、pageSize 改为 20 → 点重置 → 表单全空、请求回到默认无条件第 1 页、已选提示消失（勾选清空）、**pageSize 仍为 20**。
- [ ] **AC5 换页/改每页条数**：带筛选条件翻到第 2 页 → 请求中筛选与排序参数逐字保留、仅 `page` 变化；改 pageSize → `page` 回 1、`page_size` 变化、筛选保留。
- [ ] **AC6 表头排序**：点「订单金额」表头 → 请求 `sort_by=total_amount&sort_order=asc` 且 page=1，表头箭头向上、与响应回显 `sort_order` 一致；再点 → `desc`；第三次点（取消）→ 回默认 `created_at`/`desc`（请求显式携带，回显一致）；「订单号」列同样可排序；「客户姓名」等非白名单列无排序图标。
- [ ] **AC7 跨页勾选**：第 1 页勾选 2 条 → 翻到第 2 页勾选 1 条 → 工具栏显示「已选择 3 条」；翻回第 1 页 → 原 2 行勾选态保留。
- [ ] **AC8 勾选上限**：pageSize 调到 100，用表头全选 + 翻页累计勾满 1000 条 → 在下一页继续全选 → **被整体拒绝**，出现「最多选择 1000 条」提示，勾选数保持 1000。🧪 `applySelectionChange` 的 1000/1001 边界由 `selection.test.ts` 覆盖。
- [ ] **AC9 导出已选入口**：未勾选时「导出已选」按钮禁用；勾选 N 条后打开弹窗 → 范围只读展示「已选订单 N 条」。
- [ ] **AC10 导出筛选结果范围**：提交查询（total=T1）→ 修改草稿条件但**不点查询** → 点「导出筛选结果」→ 弹窗展示「当前筛选结果 T1 条」（不是草稿对应的新数字）。🧪 快照以 `SubmittedFilter` 为输入由 `filters.test.ts` 覆盖。
- [ ] **AC11 表单校验**：金额 min=500、max=100 点查询 → 阻止提交且金额字段出现错误提示；时间 begin=end → 阻止；手机号输入 `123` → 阻止并提示 11 位数字；清空后可正常提交。
- [ ] **AC12 弹窗校验**：弹窗内取消全部导出列 → 点确认 → 阻止并提示至少选择 1 列；文件名输入框 `showCount` 显示且**无法输入超过 100 字符**；「恢复默认」回到 6 列。
- [ ] **AC13 创建请求形态**：🧪 `exportApi.test.ts` 断言 URL/POST 方法/`Idempotency-Key` 头/`Content-Type`/两种 mode 请求体（快照 snake_case、多值为数组）/Envelope 解包。🌐 联调（后端就绪后）：勾选 3 条 + 选 2 列提交 → DevTools 确认 body 与头符合 be-td.md 4.5；提交期间确认按钮 loading，连点无第二次请求。
- [ ] **AC14 创建成功**：🌐 后端就绪后：创建成功 → 弹窗关闭、已选提示消失（勾选清空）、成功弹窗展示 job_no 与预计行数 total_rows；点「查看任务」→ 切换到导出任务页；点「留在本页」→ 停留订单页且勾选为空。
- [ ] **AC15 创建失败**（当前即可验证，后端未就绪即天然失败路径）：提交创建 → 弹窗**不关闭**、已选列与文件名保留、顶部 Alert 展示错误信息与 trace_id、勾选保留；再次点确认 → 重新发请求且 `Idempotency-Key` 为**新 UUID**。
- [ ] **AC16 查询失败**：停掉后端 → 点查询（新条件）→ 上一次表格数据仍完整显示 + 错误 Alert + 「重新加载」按钮；草稿、已提交条件、勾选全部保留；重启后端点「重新加载」→ 新数据正常返回。
- [ ] **AC17 单测与构建**：🧪 `npm test` 全绿（含 `filters.test.ts`、`selection.test.ts`、`exportApi.test.ts` 新文件与既有用例）；`npm run build`（含 tsc 类型检查）通过。
